# 大肥鱼：概念结构与方法

本文以学术术语描述「大肥鱼」的概念结构与方法构成。系统是一个长期运行的对话智能体，包含记忆子系统、动机-决策子系统、具身模拟环境、经济系统与社会交互层，并以定时任务实现自主节律。文中对每个术语给出定义、数学形式或算法描述，以及在本插件中的落地位置；同时区分「机制」（可计算、可验证）与「隐喻」（借用概念但不具备对应的物理或生理基础）。本文不主张该系统具有意识或主观体验。

## 1 系统分层

| 层 | 内容 | 代码 |
|---|---|---|
| 接入层 | AstrBot 消息监听、命令、调度、模型与向量提供商适配 | `main.py` |
| 编排层 | 把各子系统串成一个角色：对话、自主行动、定时任务 | `core/agent.py` |
| 记忆 | 编码、图 + 向量存储、巩固、检索、遗忘 | `core/memory.py`、`core/embedding.py`、`core/gua.py` |
| 动机与决策 | 六维驱力、玻恩规则抽样 | `core/drives.py`、`core/collapse.py` |
| 具身环境 | 室内房间、岛面坐标、猫与鸟、太阳、天气 | `core/world.py`、`core/sun.py`、`core/weather.py` |
| 生态与经济 | 菜地、花、食物链、厨房、金币、家具 | `core/ecology.py`、`core/economy.py` |
| 社会认知 | 关系图式、主人认证、群聊触发 | `core/social.py` |
| 模型 | 对话与成本记账 | `core/llm.py` |

### 1.1 机制与隐喻

- **机制**：有明确输入输出、可重复验证的实现，如「遗忘曲线衰减」「玻恩规则抽样」。
- **隐喻**：借用概念命名以组织设计，但不具备其物理或生理实质，如「浮空岛」「卦象」。
- 占断、命理类内容（吉凶、五行生克）不进入实现，卦象只用作 6 位状态编码的索引结构。

## 2 记忆子系统

### 2.1 记忆分区

依据多重记忆系统分类（Squire, 2004）与互补学习系统理论（McClelland et al., 1995），记忆按「脑区标签」（region）显式分区，检索时按查询意图分配注意力预算。

| region | 含义 | 写入时的判定 |
|---|---|---|
| `flash` 闪光灯 | 强情绪事件（McGaugh, 2004） | \|效价\| ≥ 0.6 且唤醒 ≥ 0.7 |
| `episodic` 情节 | 具体经历（Tulving, 1972） | 时间词：今天、昨天、上次…；默认分区 |
| `semantic` 语义 | 事实与知识 | 定义、原理类表述；巩固阶段的抽象结果 |
| `procedural` 程序 | 怎么做 | 步骤、方法类表述 |
| `social` 社会 | 人与关系 | 朋友、家人、群等 |
| `spatial` 空间 | 地点 | 房间与岛上地标 |
| `self` 自我 | 关于角色自身 | 你是、你叫… |

检索时只有意图匹配的分区不限名额，闪光灯最多 2 条，其他分区各占约三分之一。

### 2.2 编码

新信息经「候选池 → 判断」两阶段写入，写进**说话人自己的小记忆库**（§2.3）。过短、寒暄类，或与这个人的旧记忆几乎重复（惊讶度 < 0.12）的不写入，后者改为强化最相似的旧节点。别人说过相似的话不算重复。

- **惊讶度**：`s = 1 − maxᵢ Jaccard(text, mᵢ)`，即与既有记忆最大字符集相似度的补值，近似预测误差。
- **初始权重**：`w₀ = w_base · (1 + s)`，主人来源 `w_base = 4.0`，其他来源 1.5。
- **情绪效价与唤醒**：词典法估计，用于判定闪光灯记忆和情绪一致性回忆。
- **等级**：闪光灯与主人用 `/记住` 写入的为 core；`w₀ ≥ 4` 为 important；其余为 normal。

### 2.3 存储与索引

**大记忆与小记忆库**：每个人（按 QQ 号）有一个小记忆库，角色自己的经历（自主行动、日记）另有一个库。来源归属（source attribution）由「在谁的库里」决定，记忆本身不必再标注是谁说的。小库之间互不相连，编码、巩固、去重、遗忘都在各库内部进行；热库容量是全体共享的上限，由大记忆统一淘汰。

每个小库内部，记忆以有向加权图 `G = (V, E, w)` 存储：节点为命题单元，边表示时间邻近（前向 0.5、后向 0.25）、共享主题标签和共激活。每个节点附一条语义向量，构成双通道索引：图通道支持扩散激活，向量通道支持模式补全。

向量来源依次为：AstrBot 的嵌入提供商、百炼 `text-embedding-v4`（512 维）、本地特征哈希向量（512 维）。不同来源的向量互不比较。热库容量上限 5000，超出后按当前权重从低到高下沉至冷库。

### 2.4 巩固

每晚 03:00 进行系统级巩固（systems consolidation），依次执行五个算子：

| 算子 | 作用 |
|---|---|
| 重放 replay | 过去 24 小时内高惊讶或高唤醒的节点权重 ×1.15（每节点一次） |
| 合并 merge | 按 §2.7 去重规则合并近似重复节点，保留权重较高者，边重新连到保留节点 |
| 抽象 abstract | 每个库内，7 天内同一主题标签下 ≥ 3 条情节记忆，由模型概括为一条语义记忆并与来源相连；只有全部来源都在同一个群时才对该群可见 |
| 修剪 prune | 所有边权 ×0.95，低于 0.05 的边删除 |
| 迁移 transfer | 执行 §2.6 的容量淘汰，把弱节点下沉冷库 |

### 2.5 检索

**路由**：大记忆先根据谁在问、问了什么，决定调用哪些小库及权重：

| 小库 | 条件 | 权重 |
|---|---|---|
| 当前说话人的库 | 总是 | 1.0 |
| 被点名的人的库 | 问题里出现其昵称（或「主人」） | 1.0 |
| 她自己的经历库 | 总是 | 0.9 |
| 最近活跃的 8 个人的库 | 问题里有「大家 / 谁 / 群里 / 他们 / 别人」等 | 0.8 |

各库分别检索，分数乘以库权重后合并，取前 6 条。随后经可见性过滤：对方自己的和角色自己的记忆都可用；别人的记忆在群聊里只用在本群说过的，在私聊里只有主人可以问起任何人，其他人只能听到别人在群里公开说过的。

库内的三路融合打分：

- **词法**：稀有词加权重叠（按逆文档频率）与字二元组重叠，`lex = 0.6·rare + 0.4·bigram`。
- **语义**：查询与节点向量的余弦相似度。
- **结构**：以前 10 名为种子做个性化 PageRank 扩散（重启概率 0.3，12 轮），含共激活边。

融合形式：

```
score = (0.65·cos + 0.35·lex + 0.2·ppr) × nodeW × driveBias × valenceBias × regionBoost × rumination × jitter
```

- `nodeW = 0.6 + 0.4·tanh(w(t) / 3)`
- `driveBias = 1 + 0.3·(当前该驱力 / 100 − 0.5)`，节点与当前驱力相关时提权
- `valenceBias = 1 + 0.15·心情·节点效价`（情绪一致性回忆）
- `regionBoost`：flash 1.45；与查询意图匹配的分区 1.35；其余 1.0
- `jitter = 1 + U(−0.175, 0.175)·T`，T 为回忆温度，由驱力经坍缩决定：focused 0.55 / normal 1.0 / diffuse 1.45

**卦象多样性**：贪心选取结果时，已选中同卦节点的候选依次乘以 0.86、0.72、0.60，避免检索同质化（见 §3）。

检索即强化：被选中的节点 `w₀ ← w(t) + 0.4`，命中次数 +1，彼此之间增加共激活边。

**呈现**：交给模型的记忆按小库分组，组标题说明是谁的（对方说过的 / 主人说过的 / 某位群友说过的〔按当前昵称，不给 QQ 号〕/ 你自己的经历），组内每条只标大概时间（刚才、今天、昨天、前天、N 天前、上周、N 周前、N 个月前、N 年前）。

### 2.6 遗忘

- **时间衰减**：`w(t) = w₀ · exp(−Δt / τ)`，Δt 从上次访问起算，τ 按等级为 core 3650 天、important 30 天、normal 7 天。
- **反刍抑制**：6 小时内被召回 ≥ 2 次的节点在打分时乘以 `0.75^(n−1)`；≥ 4 次时权重本身 ×0.9。
- **容量淘汰**：当前权重 < 0.05、零命中、超过 30 天的节点下沉冷库；热库超容量时按权重从低到高下沉。闪光灯记忆不淘汰。

### 2.7 去重与维护

- **去重**：在每个小库内部，Jaccard ≥ 0.60 且包含度 ≥ 0.78，且同分区或共享标签时合并；闪光灯节点不参与。不同人的记忆在不同库里，不会被合并。候选对用字二元组倒排索引预筛。
- **维护**：每小时修复自环边、悬空边、缺失的分区、标签与说话人、多余向量，保证图结构不变量。

## 3 卦象状态编码（六爻编码）

六十四卦在数学上是 2⁶ 的离散状态空间。本文借其结构作为记忆的 6 位特征编码，用于结构化索引与检索多样性控制，不涉及占断语义。

编码函数：`c(node) = (b₁…b₆)`，b₁ 为初爻（最下）；下卦 = `tri(b₁b₂b₃)`，上卦 = `tri(b₄b₅b₆)`，卦名 = `Names[上卦][下卦]`。

| 爻 | 特征 | 为 1 的条件 |
|---|---|---|
| b₁ | 来源 | 主人 |
| b₂ | 效价 | ≥ 0 |
| b₃ | 唤醒 | ≥ 0.5 |
| b₄ | 等级 | core 或 important |
| b₅ | 类型 | 情节或闪光灯 |
| b₆ | 连通 | 出度 ≥ 3 |

验证：全阳 → 乾为天（111111）；全阴 → 坤为地（000000）；下乾上坤 → 地天泰；64 种输入产生 64 个互异卦名（见单元测试）。

## 4 动机与决策

### 4.1 驱力系统

六维连续状态：社交 social、好奇 curiosity、玩耍 play、休息 rest、认可 recognition、成就 achievement，取值 0–100。各维按速率上升（每小时 3 / 4 / 3 / 2.5 / 1.5 / 1），按事件下降；施加一阶惯性滤波 `v_t = 0.7·v_{t−1} + 0.3·v_target`，避免情绪突变。休息维（疲劳）≥ 80 时打盹，打盹或夜间睡眠时每小时恢复 12，≤ 25 时醒来。

### 4.2 量子式决策

动作空间取五个基态 {读, 玩, 唤醒, 安静, 学}。每个动作有两条「路径」：内在倾向振幅 `a_k = √pref_k`（由驱力线性组合得到）与情境振幅 `b_k = √ctx_k`（由时段给出），情境相位 `φ_k` 决定两者干涉：

```
ψ_k = a_k + b_k · e^{iφ_k}
P(k) = |ψ_k|² / Σⱼ |ψ_j|²,   k ~ P
```

例如夜间「安静」同相增强、「玩」「唤醒」反相相消。该形式为数学借用（quantum-like decision, Busemeyer & Bruza, 2012），不涉及物理量子过程。

### 4.3 确定性优先

为避免过度随机，当首选概率 ≥ 0.55 且领先次选 ≥ 0.15 时直接采纳，仅在选项接近时交由坍缩抽样。坍缩也用于：回忆温度、空间去处、天气模拟、菜谱、口味、猫与鸟的行为、读书选题、作物品种、拾荒收获。

## 5 具身模拟环境

### 5.1 室内层与岛面层

- **室内层**：卧室、客厅、厨房、书房、浴室、门厅。BFS 最短路；门有 open / closed / locked 三态，控制通行（locked 不可通行）、视线（仅 open 可见）与声音传播（每过一扇门衰减 0.6 / 0.25 / 0.2）；光照按窗距指数衰减 `I·exp(−d/2.5)`；温度在相邻房间按门状态扩散，并与室外交换、受日照升温；灰尘随时间累积。
- **岛面层**：地标（屋子、菜棚、阳台、水井、老树、崖边、码头）有 0–100 坐标；移动代价与距离成正比（计入休息驱力）；猫（饿 → 菜棚，近人 → 跟随，否则游荡）与鸟（白天去菜棚啄菜，夜里回老树）按速度逐时推进。

### 5.2 太阳几何与气象

太阳高度角采用天文近似：

```
sin h = sin φ sin δ + cos φ cos δ cos H
cos H₀ = −tan φ tan δ        （昼长 = 2H₀ / 15 小时）
I = max(0, sin h) · (1 − cloud)
```

δ 为赤纬，H 为时角（按经度换算的地方平太阳时，忽略时差方程）。辐射强度参与室内光照、升温与花的生长。

气象数据来自 Open-Meteo（免密钥），按 8 个地点（海、云海、森林、雪山、城市、沙漠、极夜、旧城）每小时更新温度、湿度、风速、云量、降水、UV、气压；请求失败时用坍缩抽样模拟。

### 5.3 生态与经济

- **生态链**：剩饭 → 虫（季节、湿度、降水、地点加权）→ 猫捕食；鸟白天啄菜；小动物偶尔偷吃剩饭。
- **农业**：4 块地，作物有生长量、水量、健康度、品种（普通 / 耐旱 / 抗病）；温度偏离适宜区间、缺水、高湿病害会伤害作物；温室棚（等级 1–2）提供伤害减免与保湿。
- **花卉**：阳台 4 盆，开花时提升心情；可剪花换金币。
- **经济**：金币为单一记账单位。收入来自读书、家务、喂猫、收菜、剪花、拾荒；支出为食材、种子、猫粮、家具。家具提供专门加成（光照、保暖、除味、猫亲密度、生长速度、读书收入、温室等级），每类加成有上限。

## 6 社会认知与交互

- **自我图式与关系图式**：身份、语气、边界按亲密度分级（主人 / 亲密 / 朋友 / 熟人 / 陌生 / 疑似冒充）；关系以对象为单位记录亲密度、信任与禁忌话题。
- **身份认证**：以 QQ 号判定主人，而非昵称；昵称与主人相似者标记为疑似冒充。
- **群聊参与**：相关度 `r = Σ 特征权重`（提问 1.0、兴趣词每个 0.8 至多 2.4、点名 2.0、长度 ≥ 15 字 0.5、主人发言 1.0），触发概率 `p = min(0.85, p₀ + 0.12·r)`，再乘以社交驱力先验 `0.6 + 0.8·social/100`，60 秒内刚回过则 ×0.3。被直接 @ 或引用时绕过随机触发。
- **记忆隔离**：每人一个记忆库（§2.3）。对方自己的和角色自己的记忆都可用；别人的记忆在群聊里只用在本群说过的，在私聊里只有主人可以问起任何人，其他人只能听到别人在群里公开说过的。
- **投喂联动**：主人在私聊表达「吃完了」等语义时，系统消耗角色的一份餐食并记一条事件，实现跨主体的状态同步。

## 7 运行、监控与成本

- **节律**：环境推进与自主决策、记忆摄取与向量同步（每 10 分钟）、天气与图维护（每小时）、夜间巩固（03:00）、日记（22:30）、自测（每 6 小时）、存盘（每 5 分钟）。
- **健康监测**：以「最后成功时间 vs 期望间隔」判定滞后；滞后超过 3 倍间隔时限流重跑（自愈，每任务 30 分钟最多一次）。
- **成本**：按日记录模型 token 用量与估算费用，计算近 7 日边际日耗；手动记录账户余额后估算剩余可用天数。日常空间动作全部由规则引擎完成，`/成本` 显示规则引擎占比。

## 8 效度声明与局限

- 系统不具备主观体验（qualia）；「感受」均为状态变量与文本模板的函数。
- 「量子」为数学借用，不涉及量子硬件；「卦象」为 6 位编码，不涉及占断。
- 空间为离散 / 低维连续表示，无连续物理仿真、无渲染、无独立意识的第三方智能体。
- 记忆分区、情绪与卦象编码为启发式标注，未做独立信度评估。
- 长期一致性依赖外部存储与调度；模型本身无状态。
