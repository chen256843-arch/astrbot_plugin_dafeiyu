# 大肥鱼 · astrbot_plugin_dafeiyu

一个会记事、有作息、住在浮空小岛上的长期陪伴角色，作为 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 插件运行。

她会把聊过的事写进一张带遗忘曲线的记忆图，按六维驱力决定接下来去读书、种菜、逗猫还是给你发消息，在一座有天气、日照、菜地和猫的小岛上过自己的日子，并据此和你聊天。

> **效度声明**：这是一个状态机 + 大语言模型的角色系统，不具备意识或主观体验。文中「量子」只是玻恩规则形式的数学借用，「卦象」只是 6 位状态编码，不做任何占断。被认真问到时，她会如实说明自己是程序驱动的角色。

## 特性

- **记忆闭环**：编码（惊讶度、情绪）→ 存储（有向加权图 + 语义向量）→ 夜间巩固（重放、合并、抽象、修剪、迁移）→ 三路融合检索 → 按等级衰减遗忘；强情绪记忆作为「闪光灯记忆」不合并、不淘汰、优先检索。
- **驱力与决策**：社交、好奇、玩耍、休息、认可、成就六维驱力带惯性滤波；五个基础动作用玻恩规则抽样，首选足够明确时直接采纳。
- **具身环境**：室内房间（门、光照、温度扩散、灰尘）+ 岛面坐标（屋子、菜棚、阳台、水井、老树、崖边、码头），猫和鸟各自行动；太阳高度按天文公式计算，天气来自 Open-Meteo。
- **生态与经济**：4 块菜地、4 盆花、剩饭→虫→猫的食物链、金币、商店和有上限的家具加成。
- **记得是谁说的**：每条记忆带说话人，不同的人说相似的话分别记住；和谁聊就优先想起谁说过的事，转述时标明来源，不张冠李戴。
- **社交**：只按 QQ 号认主人，昵称相似者标记疑似冒充；按亲密度分级的相处边界；群聊按相关度决定是否插话；别人私聊里的事不会在群里说出来。
- **省钱**：日常的自主行动全部由规则引擎完成，只有聊天、日记和记忆概括才调用模型；`/成本` 可看日耗和余额还能用几天。

## 安装

在 AstrBot WebUI 的「插件」页任选一种方式：

- 从链接安装：`https://github.com/chen256843-arch/astrbot_plugin_dafeiyu`
- 从文件安装：在 [Releases](https://github.com/chen256843-arch/astrbot_plugin_dafeiyu/releases) 下载 zip 上传

依赖（`httpx`、`numpy`、`tzdata`）由 AstrBot 按 `requirements.txt` 自动安装。需要 AstrBot ≥ 4.16，目前只在 OneBot v11（aiocqhttp）平台上测试过。

从零开始部署整套 QQ 机器人（QQ 小号 + SnowLuma + AstrBot + DeepSeek，Docker）见 [docs/DEPLOY.md](docs/DEPLOY.md)。

## 最少配置

在插件配置页里：

| 配置 | 说明 |
|---|---|
| 主人 QQ 号 | 你自己的 QQ 号（不是机器人账号） |
| 使用的提供商 | 选一个已在 AstrBot 里配置好的对话模型，例如 DeepSeek |

保存后用主人账号私聊机器人一次，她之后才能主动给你发消息。其余配置项都有默认值，完整说明见配置页上的提示。

几个常用的可选项：

- **群聊人设**：群里和私聊用不同的人设，例如群里更克制、私聊更亲近。
- **逐句分条发送**：回复按句切开、间隔一两秒逐条发出，更像真人打字（需要在 AstrBot 里开启「分段回复」）。
- **嵌入模型**：默认用本地哈希向量做语义检索；填 AstrBot 的嵌入提供商 ID 或百炼 `text-embedding-v4` 的 Key 可以让回忆更准。
- **时区**：作息、日记、夜间巩固都按这里的时区（默认 `Asia/Shanghai`）算，不受容器默认 UTC 影响。

## 命令

| 谁 | 命令 |
|---|---|
| 所有人 | `/状态` `/岛` `/房间` `/农场` `/日记` `/商店` `/关系` |
| 主人 | `/记忆 [关键词]`（无参数看统计，有参数看检索打分与卦象）`/记住 内容` |
| 主人 | `/购买 物品 [数量]` `/浇水` `/收菜` `/种地 [作物]` `/打扫` `/喂猫` `/剪花` `/拾荒` |
| 主人 | `/门 房间A 房间B open\|closed\|locked` `/禁忌 QQ号 话题` |
| 主人 | `/自检` `/成本` `/余额 数值` `/巩固` |

私聊直接说话即可。群聊里被 @ 或引用时必回，其余消息按 `p = min(0.85, p₀ + 0.12·r)` 决定是否插话。主人私聊说「吃完了」会触发投喂联动：她也吃掉一份做好的饭，并记下这件事。

## 和 AstrBot 的关系

- 她回复的消息会终止事件传播，AstrBot 默认的模型不会再回一遍；她不回的消息照常交给其他插件。
- 模型调用默认走 AstrBot 里选定的提供商，token 用量计入 `/成本`。也可以切到「插件自己调用」，单独填 OpenAI 兼容接口的 Key。
- 所有状态保存在 `data/plugin_data/astrbot_plugin_dafeiyu/` 下的 `state.json`、`memory.json`、`vectors.json`，更新或重装插件不会丢失。
- 插件自带一个 30 秒一轮的轻量调度循环（环境推进、记忆摄取、天气、维护、巩固、日记、自检、存盘），并对滞后任务限流自愈。

## 工作原理

设计文档见 [docs/DESIGN.md](docs/DESIGN.md)。主要公式与代码位置：

| 机制 | 公式 / 规则 | 代码 |
|---|---|---|
| 编码 | 惊讶度 `s = 1 − max Jaccard(text, mᵢ)`，`w₀ = w_base·(1+s)`，主人 4.0 / 其他 1.5 | `core/memory.py` `judge` / `write` |
| 检索 | `(0.65·cos + 0.35·lex + 0.2·PPR) × 权重 × 驱力 × 情绪 × 分区 × 说话人 × jitter`；同卦递减 0.86、0.72；当前说话人自己的记忆 ×1.25 | `MemoryStore.retrieve` |
| 遗忘 | `w(t) = w₀·exp(−Δt/τ)`，τ = 3650 / 30 / 7 天；短时反复召回降权；低权重零命中长龄下沉冷库 | `MemoryStore.weight` / `forget` |
| 去重 | Jaccard ≥ 0.60 且包含度 ≥ 0.78，且同分区或共享标签；闪光灯不参与 | `MemoryStore.dedupe` |
| 卦象 | 6 位：主人来源 / 正效价 / 高唤醒 / 高等级 / 情节性 / 高连通 → 64 卦名 | `core/gua.py` |
| 驱力 | `v_t = 0.7·v_{t−1} + 0.3·v_target`，休息 ≥ 80 打盹、≤ 25 醒来 | `core/drives.py` |
| 决策 | `ψ_k = a_k + b_k·e^{iφ_k}`，`P(k) = \|ψ_k\|² / Σ\|ψ_j\|²`；首选 ≥ 0.55 且领先 ≥ 0.15 直接采纳 | `core/collapse.py` |
| 太阳 | `sin h = sin φ sin δ + cos φ cos δ cos H`，`cos H₀ = −tan φ tan δ`，`I = max(0, sin h)(1 − cloud)` | `core/sun.py` |
| 群聊触发 | `p = min(0.85, p₀ + 0.12·r)`，r 由提问、兴趣词、点名、长度、是否主人加权 | `core/social.py` |

## 开发

核心逻辑在 `core/`，不依赖 AstrBot，可以单独测试：

```bash
python -m unittest discover -s tests
```

`main.py` 只负责 AstrBot 接入：消息监听、命令、调度和模型/向量提供商适配。

## 隐私

插件会把聊天内容以明文 JSON 存在服务器上，并发送给你配置的模型服务商。部署在群里时，请让群成员知道这一点。不要把 `data/` 目录、插件配置文件或日志提交到公开仓库。
